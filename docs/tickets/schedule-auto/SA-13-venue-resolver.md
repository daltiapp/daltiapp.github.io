# SA-13 · 기존 장소 연결과 무료 주소→GPS 변환

> 2026-09-30 변경: 신규 대회일정은 NAS에서 승인 없이 검증·커밋·푸시한다. 아래 기존 승인 중심 계획은 이 결정으로 대체하며, 현재 기준은 [최종 설계](../2026-09-29-schedule-auto-collection.md)와 스크래퍼 `SCHEDULE_AUTO.md`다. 웹 확인은 후속 기능이다.

- 단계: 1 개발 · 선행: SA-10 · 수정: 2026-09-30
- 기준: [AK-SCHEDULE-002](../2026-09-29-schedule-auto-collection.md) 4절·부록

대회일정 생성이 주 기능이며 이 티켓은 미등록 장소가 있을 때만 필요한 보조 작업이다. 기존 `venue.json` 이름·별칭·주소를 먼저 연결한다. 신규 장소는 포스터/운영자 주소를 Geoapify 무료 Geocoding API로 변환한다. Codex는 포스터 주소 추출만 하며 좌표 검색·생성을 하지 않는다.

## 구현

- scraper `schedule/auto/geocoder.py`: HTTP 의존성 주입, 국내 결과 필터, 후보·출처·라이선스 보존, 단일 건물/시설 후보, 국내 좌표·정확도·주소 대조.
- 주소 없음·API 키 없음·검색 0/복수 건·대략적 결과는 검수 대기. HTTP 오류는 재시도 가능 상태. API 키/요청 URL/오류 본문은 출력하지 않는다.
- 기존 장소와 `미정`은 외부 요청 없음. 신규 장소는 항상 사람 검수.
- `AGILITY_VENUE_LOOKUP=geoapify|none`, `AGILITY_GEOAPIFY_API_KEY`는 서버 비밀파일 전용.
- 무료 플랜 3,000 credits/일. 저장·재사용 조건과 웹/앱 출처 표시는 설계 부록 참조.
