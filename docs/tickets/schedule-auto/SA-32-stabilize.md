# SA-32 · 안정화 · 자동 반영 전환 판단

- 단계: 3 적용 · 선행: SA-31 · 기간: 2~4주

## 목적

운영 승인 모드를 안정화하고, 게이트를 통과한 신규 건만 자동 반영(`auto`)할지 판단한다.

## 작업

1. SA-22와 같은 항목으로 주간 기록(운영 기준).
2. 테스트 예약(`schedule_auto_test`, `schedule_approve_test`) 종료. 테스트 저장소·Drive 폴더는 회귀 테스트용으로 유지하거나 정리(사용자 결정).
3. 수동 수정이 반복된 필드는 SA-12 규칙·정규화표에 반영.

## `auto` 전환 판단 기준 (제안)

- 섀도 + 운영 기간 합산 무경고 오류 0건
- 게이트가 “자동 반영 가능”으로 판정한 건 중 사람이 수정한 건 0건, 표본 10건 이상
- 사용자 명시 승인

전환하면 `AGILITY_SCHEDULE_PUBLISH_MODE=auto`로 바꾸고 SA-31 4번 문서에 “게이트 통과 신규 건만 자동 반영, 변경·신규 장소·3건 이상은 승인” 정책을 적는다. 문제가 생기면 값만 `approve`로 되돌린다.
