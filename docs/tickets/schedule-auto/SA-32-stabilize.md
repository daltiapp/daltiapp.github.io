# SA-32 · 웹 승인 흐름 안정화

> 2026-09-30 변경: 신규 대회일정은 NAS에서 승인 없이 검증·커밋·푸시한다. 아래 기존 승인 중심 계획은 이 결정으로 대체하며, 현재 기준은 [최종 설계](../2026-09-29-schedule-auto-collection.md)와 스크래퍼 `SCHEDULE_AUTO.md`다. 웹 확인은 후속 기능이다.

- 단계: 3 적용 · 선행: SA-31 · 기간: 2~4주
- 2026-09-30 정정: 무검수 자동 반영 전환은 범위에서 제외한다.

1. 오판독·좌표 수정·반려·중복·배포 실패를 주간 기록한다.
2. 반복 수정되는 필드는 판독 규칙과 장소 별칭에 반영하되 운영자 승인은 유지한다.
3. 실제 주소 조회 성공률과 시설 출입구 차이, 무료 API 사용량을 점검한다.
4. 검수 웹의 동시 승인·재시도·만료 배치 처리를 확인한다.

완료: 승인 전 데이터 미반영, 승인 후 단일 커밋 배포, 장애 시 원인과 복구 상태가 표시되는 운영 기록을 남긴다. 이전 `AGILITY_SCHEDULE_PUBLISH_MODE=auto` 전환 제안은 사용하지 않는다.
